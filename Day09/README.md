# Day 9 — Cleaning Messy Real-World Data

## Objective

Clean and prepare a real-world dataset using Python and Pandas.

## Cleaning Steps

* Checked for missing values
* Removed missing records
* Detected duplicate records
* Removed duplicate records
* Standardized text formatting
* Removed extra spaces
* Saved the cleaned dataset

## Cleaning Decisions

1. Missing values were removed using `dropna()`.
2. Duplicate records were removed using `drop_duplicates()`.
3. Text columns were cleaned using `strip()` and `title()`.
4. The cleaned dataset was saved as `cleaned_day9.csv`.

## Tools Used

* Python
* Pandas
* Jupyter Notebook

## Key Learning

Data cleaning is an important step because clean and consistent data helps produce more reliable analysis and decisions.
