# Day 44 — Interactive Customer Intelligence Dashboard

## Overview

The Day 44 project focuses on building an interactive Customer Intelligence Dashboard using Streamlit.

The dashboard combines customer analytics, business KPIs, customer segmentation, churn-risk analysis, revenue trends, and profit analysis into one interactive application.

## Features

* Interactive Streamlit dashboard
* Customer CSV file upload
* Customer filtering
* Product category filtering
* KPI cards
* Customer segmentation analysis
* Customer churn-risk analysis
* Monthly revenue trend
* Profit by category
* Customer data table

## Key Performance Indicators

The dashboard displays:

* Total Revenue
* Total Profit
* Total Customers
* Total Orders

## Analytics

### Customer Segmentation

Customer segmentation results from Day 30 are displayed to understand different customer groups.

### Churn-Risk Analysis

Customer risk results from Day 41 are displayed using:

* Low Risk
* Medium Risk
* High Risk

### Business Performance

The dashboard provides visualizations for:

* Monthly revenue
* Profit by category
* Customer segment distribution
* Churn-risk distribution

## Technology Used

* Python
* Streamlit
* Pandas
* Data Visualization
* CSV datasets

## Project Files

* `app.py` — Streamlit dashboard application
* `DASHBOARD_ARCHITECTURE.md` — Dashboard architecture explanation
* `README.md` — Project documentation

## How to Run

Open PowerShell in the Day44 folder and run:

```bash
python -m streamlit run app.py
```

The dashboard will open in the browser.

## Learning Outcome

Through this project, I learned how to build an interactive business intelligence dashboard using Streamlit and integrate multiple customer analytics results into a user-friendly application.
